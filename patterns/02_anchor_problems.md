# Anchor Problems — master ~30, cover all 75

You do **not** grind 75 problems blindly. You master **2 anchors per pattern** cold
(recognize in <2 min, code from memory, test the 4 categories), then the rest of
Blind 75 becomes "which anchor is this a variation of?"

## How to use this file
1. Solve the anchor from scratch using its pattern template.
2. Log it with the existing per-problem workflow: one folder per problem,
   `solution.py` + `README.md` from `templates/problem-readme.md`, kebab-case name
   (see repo `README.md`). Two Sum already done in `two-sum/` — same format.
3. When you can code both anchors of a pattern blind, the "extras" for that
   pattern are just reps — do them faster, don't re-learn.

Legend: **[A]** = anchor (master cold). Others = variations, solve after anchors.
