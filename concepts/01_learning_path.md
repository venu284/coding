# Learning Path

This is the curriculum-first route through `concepts/`. Follow it when learning
deeply. If an interview is close, use `00_quick_revision_cards.md` and
`06_interview_revision.md` instead.

## Phase 1: Foundations

Goal: understand how to reason before choosing a pattern.

1. `foundations/01_big_o.md`
2. `foundations/02_recursion.md`
3. `foundations/03_iteration_and_invariants.md`
4. `foundations/04_math_for_dsa.md`
5. `foundations/05_python_dsa_toolkit.md`
6. `foundations/06_testing_edge_cases.md`

Practice focus:

- Rewrite brute force to optimized solutions.
- Say complexity before coding.
- Build a habit of edge-case testing.

## Phase 2: Core Data Structures

Goal: know the containers and their operation costs.

1. `data-structures/01_arrays_and_strings.md`
2. `data-structures/02_hash_maps_and_sets.md`
3. `data-structures/03_stacks_and_queues.md`
4. `data-structures/04_linked_lists.md`
5. `data-structures/05_trees_and_bsts.md`
6. `data-structures/06_heaps_priority_queues.md`
7. `data-structures/07_graphs.md`
8. `data-structures/08_tries.md`
9. `data-structures/09_union_find.md`
10. `data-structures/10_intervals.md`

Practice focus:

- Implement each structure's core operation from memory.
- Explain when the structure beats arrays or brute force.

## Phase 3: Core Algorithms

Goal: learn the reusable procedures.

1. `algorithms/01_sorting.md`
2. `algorithms/02_binary_search.md`
3. `algorithms/03_tree_traversals.md`
4. `algorithms/04_graph_traversals.md`

8. `algorithms/08_dynamic_programming.md`
9. `algorithms/09_greedy.md`
10. `algorithms/10_bit_manipulation.md`

Practice focus:

- Choose the algorithm from input shape and constraints.
- State the invariant or recurrence before coding.

## Phase 4: Interview Techniques

Goal: recognize problem shapes quickly.

1. `techniques/01_two_pointers.md`

4. `techniques/04_monotonic_stack_queue.md`

Practice focus:

- Identify the trigger in under 2 minutes.
- Type the template from memory.
- Solve one anchor and one variation per technique.

## Phase 5: Advanced Tools

Goal: handle harder interview and OA topics after the core is stable.

1. `advanced/01_segment_tree.md`
2. `advanced/02_fenwick_tree.md`
3. `advanced/03_advanced_graphs.md`
4. `advanced/04_advanced_dynamic_programming.md`
5. `advanced/05_string_algorithms.md`
6. `advanced/06_system_design_dsa.md`

Practice focus:

- Learn only after core patterns are comfortable.
- Focus on recognizing when the advanced tool is necessary.

## Weekly Rhythm

- **Mon-Thu:** one concept page, one template rewrite, one anchor.
- **Fri:** mixed review from `00_quick_revision_cards.md`.
- **Sat:** two timed problems with no topic label.
- **Sun:** re-solve weakest anchor and update notes.

## Graduation Criteria

You are ready to shift from learning to interview repetition when you can:

- explain every quick card in your own words;
- pick the right tool from `04_decision_tables.md`;
- run `python3 concepts/03_template_bank.py` successfully;
- solve each anchor in `05_practice_map.md` without looking at notes.
